# 模型网关 · 聚合与实体

## Provider（providers）

| 字段 | 类型 | 必填/默认 | 说明 |
|---|---|---|---|
| name | String | 必填，trim | 工作区/全平台唯一 |
| type | String | 必填 | OpenAI / Anthropic |
| endpoint | String | 必填 | API Base URL |
| credentialType | String | 默认 api_key | 仅 api_key |
| encryptedCredential | {iv,ciphertext,tag} | 必填 | AES-256-GCM |
| isEnabled | Boolean | 默认 true | 启用 |
| scope | String | 默认 user，index | user / global |
| tenantId / workspaceId | ObjectId | 默认 null，index | global 恒 null |

索引：
- uniq_provider_tenant_workspace_name：{tenantId,workspaceId,name} unique，partial scope=user
- uniq_provider_global_name：{name} unique，partial scope=global

插件：workspace-scope（shared + globalScopeVisible）。

## Model（models）

| 字段 | 类型 | 必填/默认 | 说明 |
|---|---|---|---|
| providerId | ObjectId → Provider | 必填，index | 所属供应商 |
| name | String | 必填 | provider 内唯一 |
| isCustom | Boolean | 默认 false | 用户自定义 |
| isEnabled | Boolean | 默认 true | 启用 |
| sortOrder | Number | 默认 0 | 排序 |
| scope | String | 默认 user，index | user / global |
| contextLength | Number | 默认 null | 正整数；null=未设置；用户模型可编辑/自动补全，人工值优先 |
| pricing.inputPerMillion | Number | 默认 0 | 整数分/百万 token |
| pricing.cachedInputPerMillion | Number | 默认 0 | 整数分/百万 token |
| pricing.outputPerMillion | Number | 默认 0 | 整数分/百万 token |
| pricing.isBillable | Boolean | 默认 true | 是否计费 |
| tenantId / workspaceId | ObjectId | 默认 null，index | global 恒 null |

索引：
- {providerId,name} unique
- {tenantId,workspaceId}（admin 侧显式命名 tenantId_1_workspaceId_1）
- scope_global_name_unique：{name} unique，partial scope=global（迁移 005 创建，schema 不声明）

规则：
- 可用模型过滤：$or [{scope:'user'}, {scope 不存在}, {scope:'global', isEnabled:true}]。
- admin 定价更新仅允许 global 模型；负价拒绝；同时 upsert productprices。
- contextLength 校验：null/缺省 = 未设置；其余必须为 ≥1 的整数，否则 `contextLength must be a positive integer`。
- 用户侧可写：`CustomModelInput.contextLength`（新增）与 `updateModelContextLength`（编辑/清空，isCustom 与同步模型均可）；global 模型前台只读，global/他人/不存在统一 `Model not found`。
- 自动补全：新增未显式传值时尽力拉取供应商上游元数据；同步模型仅补「未设置」的行，不覆盖人工值。
- 上游字段白名单：`context_length` / `context_window` / `max_context_length` / `max_input_tokens` / `input_token_limit`；不取 `max_tokens` / `max_output_tokens`（输出上限）。

## ModelProvision（下发值对象，无集合）

| 字段 | 类型 | 说明 |
|---|---|---|
| providers[] | 数组 | 恒含且仅含一个 `zag` 组且首位；结构校验允许空数组 |
| providers[].vendorId | String | `zag` 或 providerId（ObjectId 字符串） |
| providers[].displayName | String | `zag` 固定 `Agent Gear`；用户组为 provider.name |
| providers[].models[] | 数组 | 仅启用模型；顺序同模型查询（sortOrder, createdAt） |
| models[].id | String | 模型名 |
| models[].contextLength | Number? | 仅正整数携带；未设置不出现该键 |

构建规则见 70/00。cloud-controller 侧 `services/model-provision.ts` 只做结构校验（providers 数组可为空、vendorId/displayName 非空、model.id 非空、contextLength 正整数）与旧字段投影。持久化位置：`cloudcontainersecrets.modelProviders`（JSON 字符串）；旧字段 `modelIds` / `modelContextLengths` 是其扁平投影。

## ProviderModelOption（上游清单读模型，无集合）

`{ name: String!, contextLength: Int? }`：用户调用 `providerModelOptions(providerId)` 时实时拉取供应商上游模型清单的返回项；不落库、不缓存；Anthropic 清单不含上下文元数据，`contextLength` 恒 `null`。上游失败统一文案 `拉取供应商模型清单失败，请检查 API 地址和凭据是否正确`。

## OpenAI 兼容网关 `/v1/models` 条目（无集合）

| 字段 | 说明 |
|---|---|
| id | 模型名 |
| object | 固定 `model` |
| owned_by | `scope=global` 与 account Key 列举恒为 `Agent Gear`；`scope=user`（含存量无 scope）为绑定供应商 `provider.name` |
| created | 创建时间（秒） |
| context_length | 可选，`contextLength >= 1` 时返回 |

## Gateway（gateways）

| 字段 | 类型 | 必填/默认 | 说明 |
|---|---|---|---|
| controllerId | ObjectId → Controller | 必填，index | 所属控制器 |
| userId / tenantId | ObjectId | 必填，index | 归属 |
| name | String | 必填 | 1..50，[a-zA-Z0-9_-]+，控制器内唯一 |
| port | Number | 必填 | 1..65535 |
| status | String | 默认 active | active / inactive / error（仅写 active） |

索引：{controllerId,name} unique；{userId}；{controllerId,status}。

## 网关代理路由（routes/gateway-proxy.ts）

| 项 | 值 |
|---|---|
| 路由 | ALL /api/gateway/:controllerId/:name/* |
| 鉴权 | Authorization: Bearer <JWT> 或 Cookie: token |
| 查询 | Gateway.findOne({controllerId,name,status:'active'})（无 userId 过滤） |
| 未认证 | 401 Not authenticated |
| 未命中 | 404 Gateway not found or not active |
| 超时 | 30s → 502 Proxy timeout |
| 频道 | port-forward:command / port-forward:response |

## 相关错误文案（逐字，节选）

- 供应商连通性测试失败，请检查 API 地址和凭据是否正确
- Model name already exists: <names> / Model name already exists / Model name is invalid
- contextLength must be a positive integer
- 仅支持为全局模型配置计费价目
- 模型单价不能为负数
- 拉取供应商模型清单失败，请检查 API 地址和凭据是否正确
- Controller not found / Controller is not online
- Name can only contain letters, numbers, hyphens, and underscores
- Name length must be 1-50 characters
- Gateway name already exists / Maximum N gateways per controller
