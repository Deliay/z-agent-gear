# 计费与计量 · 聚合与实体

## BillingAccount（billingaccounts）

| 字段 | 类型 | 必填/默认 | 说明 |
|---|---|---|---|
| ownerType | String | 必填 | front_user（废弃）/ admin_user / tenant |
| ownerId | String | 必填 | 归属 id |
| ownerName | String | 默认 '' | 展示名 |
| cashBalance / giftBalance / creditLimit / frozenAmount | Number | 默认 0 | 整数分 |
| appliedLedgerIds | [String] | 默认 [] | 最近 N 条水位（非幂等依据） |
| invoiceSeq | Number | 默认 0 | 账单序号分配器（$inc） |
| status | String | 默认 active | active / frozen |
| insufficientSince | Date | 默认 null | 首次余额不足时间 |

索引：{ownerType,ownerId} unique。

## BillingLedger（billingledgers）

| 字段 | 类型 | 必填/默认 | 说明 |
|---|---|---|---|
| accountId | ObjectId | 必填，index | 账户 |
| pool | String | 必填 | cash / gift / credit |
| bizType | String | 必填 | recharge / charge / freeze / unfreeze / settle / adjust |
| deltaBalance / deltaFrozen | Number | 默认 0 | 整数分 |
| allocations | [{pool,amount}] | 默认 [] | 拆池明细 |
| bizId | String | 默认 null | 业务 id（预留前缀 reservation:<id>:） |
| idempotentKey | String | 必填 | unique |
| walletApplied | Boolean | 默认 false | 历史兼容信号 |

索引：idempotentKey unique；{accountId,createdAt}。
**追加式**：所有 update/delete 被拒绝。

## BillingAppliedLedger（billingappliedledgers）

| 字段 | 类型 | 说明 |
|---|---|---|
| accountId / ledgerId | ObjectId / String | 归属 |
| walletApplied | Boolean | 默认 false |
| appliedAt / claimedAt | Date | 应用时间 / 租约认领 |

索引：{accountId,ledgerId} unique；{accountId}；{claimedAt}。
状态：pending / in-flight（租约内）/ applied / stale（可接管自愈）。

## BillingReservation（billingreservations）

| 字段 | 类型 | 必填/默认 | 说明 |
|---|---|---|---|
| accountId | ObjectId | 必填，index | 账户 |
| resourceId | String | 必填 | unique（一个资源一条） |
| resourceType | String | 默认 container | 仅 container |
| productId | String | 默认 container.minute | 计费产品 |
| status | String | 默认 PENDING | PENDING / ACTIVE / SETTLING / SETTLED / RELEASE_PENDING / FAILED |
| depositCents / cycleEstimateCents | Number | 默认 0 | 保证金 / 每周期预估 |
| reservedTotal / settledTotal / releasedTotal | Number | 默认 0 | 累计 |
| lastSettleAt / lastCycleSeq | Date / Number | — / -1 | 结算窗口游标 |
| startedAt / expectedEndAt | Date | — / null | 时间 |
| version | Number | 默认 0 | CAS 版本 |

索引：{resourceId} unique；accountId；status。

## BillingReservationCycle（billingreservationcycles）

| 字段 | 类型 | 说明 |
|---|---|---|
| reservationId | ObjectId | index |
| cycleSeq | Number | 周期序号 |
| windowFrom / windowTo / minutes / amount | — | 结算窗口与金额（分） |
| status | String | settled / skipped |

索引：{reservationId,cycleSeq} unique。

## BillingInvoice（billinginvoices）

| 字段 | 类型 | 说明 |
|---|---|---|
| accountId / seq | ObjectId / Number | {accountId,seq} unique，seq 从 0 连续 |
| type | String | charge / recharge / adjust |
| category | String | container / model / manual / storage |
| amount | Number | 整数分；消费为负、充值为正 |
| balanceAfter | Number | 记账后现金余额 |
| refType / refId | String | 关联资源（如 cloud_storage） |
| idempotentKey | String | partial unique |
| description / items | String / 子文档[] | 明细 |
| receiptId / periodFrom / periodTo | — | 收据与账期 |

Item：productId、quantity、unitPrice、amount、meteringRef、segment（input / cached_input / output，中断后缀 :aborted）。
**追加式**：update/delete 被拒绝。
中断计费：input:aborted=20% 未缓存、cached_input:aborted=80% 缓存、output:aborted 全价。

## BillingRollup（billingrollups）

| 字段 | 类型 | 说明 |

## MeteringRecord（meteringrecords）

| 字段 | 类型 | 说明 |

## BillingApiCall / BillingApiKey

### BillingApiCall（billingapicalls）

| 字段 | 类型 | 说明 |
|---|---|---|
| requestId | String | unique |
| accountId / apiKeyId / cloudHostId | ObjectId | 归属与归因 |
| billable | Boolean | false=自定义模型代转发，不计费仅审计 |
| modelId / modelName | String | 模型 |
| inputTokens / cachedInputTokens / outputTokens | Number | 实际用量 |
| cost | Number | 整数分（折后） |
| status | String | started / completed / aborted / failed |
| invoiceSeq | Number | 关联账单 |
| estimated | Boolean | 估算标记 |

### BillingApiKey（billingapikeys）

| 字段 | 类型 | 说明 |
|---|---|---|
| accountId / ownerType / ownerId | — | 归属 |
| name / keyPrefix / keyHash | String | 明文仅返回一次，库内 bcrypt |
| status | String | active / revoked |
| scope | String | account / cloud_host |
| cloudHostId | ObjectId | 仅 cloud_host 非空 |
| expiresAt | Date | 历史遗留，新 Key 恒 null |
| lastUsedAt | Date | 最近使用 |

校验规则：keyPrefix 定位最多 5 条 active 候选 → bcrypt；scope=cloud_host 还要求云电脑存在、未软删、status=RUNNING，否则 401 invalid_api_key。

## CloudBillingCursor（cloudbillingcursors，admin-api 独占写）

| 字段 | 类型 | 说明 |
|---|---|---|
| resourceId | String | unique（一容器一条，与 billingreservations.resourceId 同口径） |
| hostId / hostName | String | 云电脑快照（出账 refId） |
| accountId / tenantId | String | 计费归属 |
| specId / specName | String | 规格快照 |
| specCpu / specMemoryGi / specEphemeralStorageGi | Number | 计费资源量快照 |
| billingStartedAt | Date | 桶锚点（= container.ready 的 billingStartedAt） |
| chargedMinutes / lastChargedAt | Number / Date | 已结算进度（整桶 +60，尾段按实际分钟；$max 推进） |
| destroyedAt | Date | 销毁事件时刻（收到 container.destroyed 写入）；非空即待尾段结算，供 tick 重试兜底 |
| closedAt / lastError | Date / String | 尾段结算收口 / 失败即停下个 tick 重试 |
| arrearsDestroyedAt | Date | 欠费宽限到期强拆发起时刻（幂等标记；强拆后由 destroyed 事件收口） |

仅承载新版云电脑（container.ready 带 spec）；0 费用规格也建游标但不出账。

## 错误码

前台/内部 REST：INVALID_BODY（400）、ACCOUNT_NOT_FOUND（404）、ACCOUNT_FROZEN（403）、INSUFFICIENT_BALANCE（409，附 available）、invalid_api_key（401）、insufficient_quota（402）、model_not_found（404）、model_not_priced（400/404）。

对账线：funds / metering / resources / events / rollups / apiCalls / containerInvoices / cloud-host-keys；未知线报 unknown reconciliation line: <line>。
