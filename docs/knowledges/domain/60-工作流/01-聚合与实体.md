# 工作流 · 聚合与实体

## WorkflowTemplate（workflowtemplates）

| 字段 | 类型 | 必填/默认 | 说明 |
|---|---|---|---|
| userId | ObjectId → User | 可空 | null + isBuiltin=true 为内置 |
| tenantId | ObjectId → Tenant | 默认 null | 内置可空 |
| name | String | 必填 | 模板名称 |
| resourceWorkspaceId | ObjectId → Workspace | 默认 null | 租户工作区 |
| description / version | String / Number | — / 1 | — |
| nodes | 子文档[] | 默认 [] | 节点图 |
| isBuiltin | Boolean | 默认 false | 内置不可改不可删 |
| createdBy | String | 默认 HUMAN | HUMAN / AI |
| createdBySessionId | ObjectId → Session | 默认 null | AI 创建来源 |

节点子文档：nodeKey（模板内唯一）、type（HUMAN/AI/FLAG）、name、description、stage、prompts、artifactTitles、dependsOn、requiresWorktree、linkUpstreamPullRequest、reworkSessionBehavior（NEW_SESSION/ORIGINAL_SESSION，缺省 ORIGINAL）、reworkCompactOriginalContext、resumeSessionBehavior（缺省 NEW_SESSION）、resumeCompactOriginalContext、sortOrder。

索引：{userId,createdAt}。插件：workspace-scope（workspaceField=resourceWorkspaceId，builtinVisible=true）。

## ConfiguredWorkflow（configuredworkflows）

| 字段 | 类型 | 必填/默认 | 说明 |
|---|---|---|---|
| userId / tenantId / controllerId | ObjectId | 必填 | 归属与目标控制器 |
| resourceWorkspaceId | ObjectId → Workspace | 默认 null | 租户工作区 |
| name | String | 必填 | 名称 |
| sourceTemplateId / sourceTemplateVersion | ObjectId / Number | 可空 | 复制来源（仅展示） |
| sourceKind | String | 默认 PLATFORM | PLATFORM / REPO |
| sourceRepoPath | String | 默认 null | .zag/workflow/templates/<fileName> |
| sourceWorkspaceId | ObjectId → ControllerWorkspace | 默认 null | 模板所在项目工作区 |
| nodes | 子文档[] | 默认 [] | 与模板同构 + agentConfig |
| createdBy / createdBySessionId | String / ObjectId | — | AI 资源门禁依据 |

agentConfig：{acpServerType（必填且须在控制器可用列表）, modeId?, modelId?, initNewWorktree（默认 false）}。
索引：{userId,controllerId}。

REPO 来源规则：仅云控制器（repo workflow only supports cloud host）；fileName 必须 .json 且不含路径分隔与 ..；名称 1..64；服务端不回读仓库文件（快照语义）。

## WorkflowInstance（workflowinstances）

| 字段 | 类型 | 必填/默认 | 说明 |
|---|---|---|---|
| userId / tenantId / controllerId | ObjectId | 必填 | 归属 |
| workspaceId | ObjectId → ControllerWorkspace | 必填 | **项目工作区** |
| resourceWorkspaceId | ObjectId → Workspace | 默认 null | 租户工作区 |
| configuredWorkflowId | ObjectId → ConfiguredWorkflow | 默认 null | 来源 |
| name | String | 必填 | 实例名（1..64） |
| nodes | 子文档[] | 默认 [] | 节点实例 |
| currentNodeNames | [String] | 默认 [] | 全部 RUNNING 节点名 |
| blackboard / blackboardTrash | Map<String,String> | 默认 {} | 产物与打回记录 |
| blackboardUpdatedAt | Map<String,Date> | 默认 {} | 每个 key 更新时间 |
| additionalPrompts | Map<String,String> | 默认 {} | 系统键 github-pr / github-pr-review |
| finishedAt / deletedAt / archivedAt | Date | 默认 null | 完成/软删/归档 |
| lastNodeName / lastNodeStatus | String | 默认 null | 最后执行节点 |
| workflowWorktreePath / workflowWorktreeBranch | String | 可空 | 实例级 worktree |
| worktreeCommitterName/Email、worktreeCoAuthorName/Email | String | 默认 null | 提交身份快照 |
| worktreeCleanupFailed | Boolean | 默认 false | 删除时清理失败 |
| continuationHistory | 子文档[] | 默认 [] | {from/toControllerId, from/toWorkspaceId, at} |

索引：{userId,workspaceId,createdAt}、{configuredWorkflowId}、{userId,archivedAt,createdAt}、{userId,controllerId,archivedAt,createdAt}、{'nodes.nextRetryAt'} partial。

节点实例字段：nodeId、nodeKey、type、name、description、stage、status、dependsOn、sessionId、createdAt、startedAt、reworkedAt、reworkCount、retryCount、nextRetryAt、retryPhase、retryDeadlineAt、retryTrigger、rejectInfo、failInfo、prompts、artifactTitles、agentConfig、requiresWorktree、linkUpstreamPullRequest、四个会话行为字段、sortOrder。

failInfo.source：SESSION_STUCK / LLM_REPORTED / SESSION_START_FAILED / RETRY_EXHAUSTED / CONTROLLER_UNAVAILABLE / MANUAL。

黑板 key 约定：
- 产物：{nodeId}-{nodeName}-产物-{title}
- 打回记录：打回-{nodeId}-{序号}

| userId / tenantId / controllerId | ObjectId | 归属 |
| configuredWorkflowId / configuredWorkflowName | ObjectId / String | 工作流与名称快照 |

## 相关错误文案（逐字，节选）

- 工作流模板至少需要 1 个节点
- 节点标识（nodeKey）重复：<keys>
- AI 节点「<name>」（<key>）至少需要 1 条提示词（prompts）
- <HUMAN|FLAG>节点「<name>」（<key>）不允许配置提示词（prompts）
- 仅人类节点可开启「联动上游 Pull Request」：节点「<name>」类型为 <type>
- 工作流模板存在循环依赖，环上节点：<a → b>
- 首节点必须唯一：入度为 0 的节点应有且仅有 1 个
- 首节点必须是人类节点（HUMAN）
- 内置模板不允许修改 / 不允许删除
- AI 节点「<name>」的 acpServerType「<type>」不在该控制器可用列表内
- repo workflow only supports cloud host / invalid template file name / invalid workflow name
- 节点「<name>」已开始，不可修改（仅从未开始过的节点可编辑）
- 节点「<name>」不是人类节点，不能人工完成
- 仅 AI 节点支持立即失败
- 工作流实例不可用（控制器离线或已删除），请先接续后再操作
- 实例已被并发接续或状态已变化，请刷新后重试
- 节点「<name>」当前状态为 <status>，不允许执行「<label>」（<event>）
- 节点「<name>」是首节点，没有上游节点可打回
- workflow has no human node / human node timeout / workflow interrupted
- 仅失败的操作可以重试
