# 控制器 · 聚合与实体

## Controller（controllers）

| 字段 | 类型 | 必填/默认 | 约束 | 说明 |
|---|---|---|---|---|
| userId / tenantId | ObjectId | 必填 | index | 归属 |
| workspaceId | ObjectId → Workspace | 默认 null | index | 租户工作区 |
| name | String | 默认 空串 | — | 云电脑为用户命名 |
| hostname | String | 必填 | — | 主机名 |
| type | String | 必填 | local / cloud / github | 接入类型 |
| status | String | 默认 registering | online / offline / registering / unbound | 在线状态 |
| keyId | ObjectId → ControllerKey | 必填 | unique | 一控制器一 Key |
| version | String | 必填 | — | 云预创建为 0.0.0 |
| lastHeartbeatAt / lastIp | Date / String | 可空 | — | 心跳 |
| worktreeDir / homeDir / platform | String | 可空 | — | 执行侧环境 |
| defaultMcp.useAllEnabled | Boolean | 默认 true | — | 默认 MCP 策略 |
| defaultMcp.serverIds | [ObjectId → McpServer] | 默认 [] | — | useAllEnabled=true 时归一为空 |

索引：keyId unique；{userId,status}。
插件：agent-api 挂 tenant + workspace；controller-api 镜像仅 tenant-scope。

## ControllerKey（controllerkeys）

| 字段 | 类型 | 必填/默认 | 约束 | 说明 |
|---|---|---|---|---|
| userId / tenantId | ObjectId | 必填 | index | 归属 |
| workspaceId | ObjectId → Workspace | 默认 null | index | 注册时继承 |
| name | String | 必填 | — | 名称 |
| type | String | 必填 | local / cloud / github | — |
| keyHash | String | 必填 | unique | bcrypt(10) |
| keyPrefix | String | 必填 | — | rawKey 前 8 位 |
| status | String | 默认 active | active / revoked / expired | — |
| boundControllerId | ObjectId → Controller | 默认 null | — | 未绑定为 null |
| lastUsedAt | Date | 可空 | — | — |

索引：keyHash unique；{userId,status}。
规则：
- rawKey 格式 zag_k_1_<48 hex>，明文仅返回一次。
- 同时只允许一把未绑定 Key（create 会清理旧未绑定 Key 并 evict）。
- 云电脑用独立 createCloudKey（直接绑定 controllerId），不复用 create。
- regenerate：云控制器拒绝；否则换 hash/prefix、Controller 置 unbound、evict、下发 shutdown。

## ControllerWorkspace（controllerworkspaces）

| 字段 | 类型 | 必填/默认 | 说明 |
|---|---|---|---|
| userId / tenantId | ObjectId | 必填 | 归属（可见性跟随控制器） |
| controllerId | ObjectId → Controller | 必填 | index |
| name | String | 必填 | 默认取路径末段 |
| path | String | 必填 | 绝对路径 |
| isEnabled | Boolean | 默认 true | 启用开关 |
| isGitRepo | Boolean | 默认 null | 检测后回写 |
| defaultBranch | String | 默认 null | 解析后回填 |

索引：{userId,controllerId}（非唯一）。
插件：仅 tenant-scope（不挂 workspace-scope）。

规则：
- 与 Workspace 是两个概念。
- 每控制器最多 10 个（MAX_WORKSPACES=10，超限 Maximum workspaces reached）。
- {controllerId,path} 在团队内幂等共享。
- 删除前 archiveByWorkspace；失败中止。
- detectGitRepo / createFolder / initGitRepo 要求控制器 online，否则 Controller is offline。
- 异步结果走 Redis 结果键：git:check:{requestId}、fs:mkdir:{requestId}、git:init:{requestId}。

## McpProxyKey（mcpproxykeys，controller-api）

| 字段 | 类型 | 必填/默认 | 说明 |
|---|---|---|---|
| userId | String | 必填 | 归属（无 ObjectId ref） |
| name | String | 必填 | 路由层 1..100，[a-zA-Z0-9\s\-_]+ |
| keyHash | String | 必填 | bcrypt，toJSON 删除 |
| keyPrefix | String | 必填 | 前缀 + 后缀掩码 |
| status | String | 默认 active | active / revoked |
| lastUsedAt | Date | 可空 | 使用即更新 |

索引：{userId,name} unique。
规则：rawKey 格式 mcp_<48 hex>，明文仅创建返回一次；重名 → HTTP 409 Key name already exists。

## Gateway（gateways）—— 端口网关（详见 70-模型网关）

| 字段 | 类型 | 必填/默认 | 说明 |
|---|---|---|---|
| controllerId | ObjectId → Controller | 必填 | index |
| userId / tenantId | ObjectId | 必填 | 归属 |
| name | String | 必填 | 1..50，[a-zA-Z0-9_-]+，控制器内唯一 |
| port | Number | 必填 | 1..65535 |
| status | String | 默认 active | active / inactive / error（仅写 active） |

索引：{controllerId,name} unique；{userId}；{controllerId,status}。

## 相关错误文案（逐字）

- Controller not found
- Controller is not online
- Controller is offline
- cloud controller cannot be renamed / unbound / key cannot be regenerated
- Maximum workspaces reached
- Workspace already exists
- Workspace not found
- Name can only contain letters, numbers, hyphens, and underscores
- Name length must be 1-50 characters
- Gateway name already exists
- Maximum N gateways per controller
- MCP_SERVER_NOT_FOUND / MCP_SERVER_NOT_SELECTABLE
