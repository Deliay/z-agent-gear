# 身份与租户 · 聚合与实体

## Account（accounts）

| 字段 | 类型 | 必填/默认 | 约束 | 说明 |
|---|---|---|---|---|
| username | String | 必填 | unique，2..20 | 登录名唯一性的唯一裁决面 |
| passwordHash | String | 必填 | bcrypt | 哈希 |
| passwordless | Boolean | 默认 false | — | OAuth 开户为 true |

索引：username 唯一。
写方：agent-api（开户 / OAuth 开户）；admin-api 只读镜像（无长度约束）。

## User（users）

| 字段 | 类型 | 必填/默认 | 约束 | 说明 |
|---|---|---|---|---|
| username | String | 必填 | unique，2..20 | 迁移遗留，不参与登录 |
| passwordHash | String | 必填 | — | 迁移遗留 |
| name | String | 可空 | — | 展示名 |
| tenantId | ObjectId → Tenant | 可空 | index | personal 场景等于 _id |
| accountId | ObjectId → Account | 可空 | index | 登录账户 |
| globalPermissionTimeoutAction | String | 默认 allow_once | allow_once / reject / cancel | 全局权限超时动作 |

字段级 resolver：User.tenant（personal 回退视图；memberCount 取 TenantMember 计数）。

## Tenant（tenants）

| 字段 | 类型 | 必填/默认 | 约束 | 说明 |
|---|---|---|---|---|
| name | String | 必填 | unique | personal 开户时等于 username |
| type | String | 默认 personal | personal / team | 归属类型 |

## TenantMember（tenantmembers）

| 字段 | 类型 | 必填/默认 | 约束 | 说明 |
|---|---|---|---|---|
| tenantId | ObjectId → Tenant | 必填 | index | — |
| userId | ObjectId → User | 必填 | index | — |
| role | String | 默认 developer | admin / developer | 权限唯一事实源 |
| createdBy | String | 默认 null | — | 操作来源（admin id / userId / migration / provision / rollback） |

索引：{tenantId,userId} 唯一。
插件：**不挂** tenant-scope / workspace-scope（自带双维度，用户可同时属多个租户）。

不变量：
- personal 恒 1 行 role=admin。
- 仅 team 可增删改成员。
- 最后一名 admin 不可移除/降级。
- 移除成员级联删除其本租户全部 workspacemembers。

## AuthProvider（authproviders）

| 字段 | 类型 | 必填/默认 | 约束 | 说明 |
|---|---|---|---|---|
| type | String | 必填 | oidc / github_oauth | 协议类型 |
| displayName | String | 必填 | trim | github_oauth 恒为 GitHub |
| issuer | String | 默认 null | — | OIDC 必填 |
| clientId | String | 必填 | — | — |
| encryptedClientSecret | {iv,ciphertext,tag} | 必填 | 三者必填 | AES-256-GCM |
| scopes | String | 默认 null | — | OIDC 空格分隔 |
| enabled | Boolean | 默认 false | — | 创建后显式启用 |
| enableFrontLogin | Boolean | 默认 true | — | 前台登录 |
| enableAdminLogin | Boolean | 默认 false | — | 后台登录 |

索引：uniq_auth_provider_github（{type} 唯一，partial type=github_oauth）；{type,enabled}。
写方：admin-api 唯一写；agent-api 只读镜像。
出参：恒不含 clientSecret，用 hasSecret 表达；更新时省略 clientSecret = 保持不变。

## ExternalLogin（externallogins）

| 字段 | 类型 | 必填/默认 | 说明 |
|---|---|---|---|
| userId / tenantId / accountId / providerId | ObjectId | 必填 | 归属与身份提供方 |
| issuer | String | 默认 null | OIDC 命名空间；GitHub 为空 |
| subject | String | 必填 | OIDC sub / GitHub 用户 id |
| externalUsername | String | 必填 | login / preferred_username |
| displayName / avatarUrl | String | 默认 null | — |
| lastLoginAt | Date | 默认 null | 登录时刷新 |

索引：uniq_external_login_subject（{providerId,issuer,subject}）；uniq_external_login_user_provider（{userId,providerId}）；{userId}。
插件：applyTenantScope。
解绑拒绝：passwordless=true 且最后一条 → cannot unbind last login method。

## AdminUser（admin_users）

| 字段 | 类型 | 必填/默认 | 说明 |
|---|---|---|---|
| username | String | 必填 | unique，trim |
| passwordHash | String | 必填 | bcrypt |
| mustChangePassword | Boolean | 默认 true | 首登强制改密 |
| passwordChangedAt | Date | 默认 null | 旧 token 失效依据 |

规则：登录失败文案恒 Invalid username or password（含恒定时间比较）；改密要求 ≥10 且非弱口令、不得与旧密码相同；mustChangePassword=true 时业务接口返回 MUST_CHANGE_PASSWORD（白名单 adminMe / adminLogin / changeAdminPassword）。

## AdminExternalLogin（adminexternallogins）

| 字段 | 类型 | 必填/默认 | 说明 |
|---|---|---|---|
| adminUserId | ObjectId → AdminUser | 必填 | index |
| providerId | ObjectId → AuthProvider | 必填 | — |
| issuer / subject | String | null / 必填 | 身份锚点 |
| externalUsername | String | 必填 | — |
| displayName | String | 默认 null | — |
| lastLoginAt | Date | 默认 null | — |

索引：uniq_admin_external_login_subject（{providerId,issuer,subject}）；uniq_admin_external_login_admin_provider（{adminUserId,providerId}）。

## 错误文案白名单（逐字）

- invalid or expired pending token
- Invalid username or password
- identity already bound / provider already bound
- provider unavailable / provision failed
- cannot unbind last login method
- external login not found
- personal tenant is immutable
- last admin cannot be removed / last admin cannot be demoted
- account not found
