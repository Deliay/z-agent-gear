# 会话与交互 · 聚合与实体

## Session（sessions）

| 字段 | 类型 | 必填/默认 | 说明 |
|---|---|---|---|
| userId / tenantId | ObjectId | 必填，index | 归属 |
| workspaceId | ObjectId → Workspace | 默认 null | 租户工作区 |
| controllerId | ObjectId → Controller | 必填 | 执行侧 |
| controllerName | String | 必填 | 名称快照 |
| acpServerType | String | 必填 | opencode / github_copilot / claude_code / gemini_cli / codex / mimo_code / kimi_code / deepseek_harness |
| status | String | 默认 creating | creating / connecting / idling / running / disconnected / ended |
| title | String | 默认 New Session | — |
| externalSessionId | String | 可空 | ACP 会话 id |
| cwd / worktreePath / worktreeBranch | String | 可空 | 工作目录与 worktree |
| endedAt | Date | 可空 | 结束时间 |
| modes / currentModeId | 子文档[] / String | 默认 [] | 模式 |
| currentModel / currentModelId / availableModels | 子文档 | — | 模型快照 |
| configOptions | 子文档[] | 默认 [] | {id,name,description,category,type,currentValue,options} |
| promptCapabilities | 子文档 | 可空 | image / audio / embeddedContext |
| agentInfo / authMethods / authRequired | — | — | Agent 能力 |
| supportsAdditionalDirectories | Boolean | 默认 false | — |
| agentCapabilities | Mixed | 可空 | controller 上报快照 |
| permissionTimeoutAction | String | 默认 use_global | use_global / allow_once / reject / cancel |
| workflowInstanceId / workflowNodeId | ObjectId / String | 可空 | 节点会话打标（不对 GraphQL 暴露） |
| archivedAt | Date | 默认 null | 归档时间 |
| controllerWorkspaceId | ObjectId → ControllerWorkspace | 默认 null | 项目工作区 |

索引：{userId,createdAt}、{controllerId,status}、{tenantId,workspaceId}、{userId,archivedAt,createdAt}、{controllerId,controllerWorkspaceId}。
插件：tenant-scope + workspace-scope。

controller-api 镜像差异：多 disconnectedAt、initialConfigError；缺 workspaceId、worktree*、permissionTimeoutAction、archivedAt、controllerWorkspaceId；仅 tenant-scope。

## AcpMessage（acpmessages）

| 字段 | 类型 | 必填/默认 | 说明 |
|---|---|---|---|
| sessionId | ObjectId → Session | 必填，index | 所属会话 |
| direction | String | 必填 | input / output |
| type | String | 必填 | text / image / tool_call / tool_result / plan / error |
| content | Mixed | 必填 | 消息内容 |
| metadata | Mixed | 可空 | parts 模式下为 {parts} JSON |
| messageId | String | 可空，index | 外部消息 id |

索引：{sessionId,createdAt}、{sessionId,messageId}。
无 userId/tenantId；**仅靠会话归属鉴权**。

## SessionInteraction（sessioninteractions）

| 字段 | 类型 | 必填/默认 | 说明 |
|---|---|---|---|
| userId / tenantId / sessionId | ObjectId | 必填，index | 归属 |
| interactionId | String | 必填 | unique uniq_session_interaction_id（幂等键） |
| kind | String | 必填 | ELICITATION / PERMISSION |
| status | String | 默认 PENDING | PENDING / ACCEPTED / DECLINED / CANCELLED / EXPIRED / FAILED |
| mode | String | 可空 | form / url（仅 elicitation） |
| message | String | 可空，≤4000 | 说明/标题 |
| requestedSchema | Mixed | 可空 | 表单 schema |
| url | String | 可空，≤2048 | 仅 http/https |
| elicitationId | String | 可空 | sparse index |
| toolCallId / toolCall / options | — | 可空 | 权限审批上下文 |
| response | 子文档 | 可空 | action / outcome / optionId / values |
| expiresAt / respondedAt / resolvedAt | Date | 可空 | 作答有效期（提问 300s / 权限审批 60s） |
| history | 子文档[] | 默认 [] | {state,at,actor,detail} |

索引：interactionId unique；{sessionId,createdAt}；{sessionId,status,expiresAt}；{elicitationId} sparse。
插件：tenant-scope。

## SessionReview（sessionreviews）

| 字段 | 类型 | 必填/默认 | 说明 |
|---|---|---|---|
| userId / tenantId / sessionId / controllerId | ObjectId | 必填 | 归属 |
| files | 子文档[] | 默认 [] | {path,absPath} |
| summary | String | 可空 | 摘要 |
| status | String | 默认 PENDING | PENDING / APPROVED / REJECTED / COMMENTED / CANCELLED |
| fileReviews | Mixed | 可空 | {file: ReviewComment[]} |
| comment | String | 可空 | 总体意见 |
| cancelReason | String | 可空 | timeout / session_closed |
| resolvedAt | Date | 可空 | 终态时间 |

索引（迁移 023）：{userId,status,createdAt}、{sessionId,status}。
CAS 未命中 → Review not found or already resolved。

## TodoItem（todoitems）

| 字段 | 类型 | 必填/默认 | 说明 |
|---|---|---|---|
| userId / tenantId | ObjectId | 必填，index | 归属 |
| type | String | 必填 | permission_request / elicitation_request / harness_login_request / workflow_intervention |
| priority | String | 必填 | immediate / urgent / medium / low |
| title | String | 必填 | 按场景生成 |
| description | String | 可空 | — |
| isRead | Boolean | 默认 false | — |
| data / elicitationData / harnessLoginData | 子文档 | 可空 | 分场景载荷（requestId、sessionId、toolCall、schema、url 等） |
| expiresAt | Date | 可空 | 通知 TTL（5 分钟；harness 默认 1800s） |
| resolution | String | 无默认 | accepted / declined / cancelled / expired / failed |
| resolvedAt | Date | 可空 | — |

索引：{userId,isRead}、{userId,createdAt}、elicitationData.requestId、harnessLoginData.requestId、{expiresAt} TTL。
插件：tenant-scope。

## 会话相关错误文案（逐字，节选）

- Session not found / Session is not ended / session is ended
- empty prompt / prompt parts too large
- existingWorktreePath and enableWorktree are mutually exclusive
- existingWorktreePath does not belong to this workspace
- WORKTREE_ADD_FAILED: <error> / WORKTREE_REMOVE_FAILED: <error>
- MCP_SERVER_NOT_FOUND: some selected MCP servers are invalid or disabled
- MCP endpoint 创建失败：<err>
- ARCHIVE_WORKFLOW_SESSION_UNSUPPORTED
- unsupported harness type: <type> / cloud host is not running
- Todo item not found or already handled
- Review not found or already resolved
- custom mcp server not found
