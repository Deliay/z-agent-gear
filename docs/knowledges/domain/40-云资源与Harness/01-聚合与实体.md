# 云资源与 Harness · 聚合与实体

## CloudHost（cloudhosts）

| 字段 | 类型 | 必填/默认 | 说明 |
|---|---|---|---|
| userId / tenantId | ObjectId | 必填 | 创建人与租户 |
| name | String | 必填，1..64 | 用户命名 |
| harnessTypes | [String] | 默认 [] | OPENCODE / KIMI_CODE / DEEPSEEK_HARNESS |
| status | String | 默认 STARTING | STARTING / RUNNING / STOPPING / STOPPED / FAILED |
| controllerId | ObjectId → Controller | 必填 | 专属 cloud 控制器 |
| keyId | ObjectId → ControllerKey | 必填 | scope=cloud_host 模型 Key |
| workspaceId | ObjectId → ControllerWorkspace | 默认 null | 项目工作区（Git clone 后 CAS 回写） |
| resourceWorkspaceId | ObjectId → Workspace | 默认 null | 租户工作区（GraphQL workspaceId 映射此字段） |
| containerId | String | 默认 null | 当前容器 |
| storageId | ObjectId → CloudStorage | 默认 null | 挂载存储 |
| defaultSessionId | ObjectId → Session | 默认 null | 默认会话 |
| githubAccountId | ObjectId → GitHubAccount | 默认 null | 创建期可选锁定，首次 Git 设置 CAS 绑定一次 |
| createDefaultSession | Boolean | 默认 true | ready 是否建默认会话 |
| startedAt / readyAt / stoppedAt | Date | null | 时间戳 |
| failureReason | String | null | 失败原因 |
| deletedAt | Date | null | 软删除 |

索引：{userId,status}、{controllerId}；**无活跃唯一索引**。
插件：tenant-scope + workspace-scope（workspaceField=resourceWorkspaceId）。
派生：hasDefaultWorkspace=Boolean(workspaceId)；storageRestoring=status=STARTING 且 currentArchive 非空；agentGearVersion 为字段级读模型（current 来自 CloudContainer.agentGearVersion，latest 来自 Redis `agent-gear:latest-version`，不落库）。

## CloudHostSetupOperation（cloud_host_setup_operations）

| 字段 | 类型 | 说明 |
|---|---|---|
| userId / tenantId / controllerId / hostId | ObjectId | 归属 |
| kind | String | installWorkload / githubSetup |
| status | String | RUNNING / SUCCEEDED / FAILED |
| workloadId / installParams | ObjectId / Mixed | 安装参数 |
| accountId / repoFullName / targetPath | — | Git 设置参数（内部字段） |
| setupWorkloadIds | [ObjectId] | 额外 standard 负载 |
| steps | 子文档[] | key=workload/gitSetup/session；status=PENDING/RUNNING/SUCCEEDED/FAILED/SKIPPED |
| batchId / containerId / sessionId | — | 执行产物 |
| error | String | 脱敏并截断 512 |

规则：同 controllerId 同时只允许一个 RUNNING 的 githubSetup；仅 FAILED 可重试；RUNNING 超时标记 FAILED「操作已中断，请重试」。

## HarnessConfig（harnessconfigs）

| 字段 | 类型 | 说明 |
|---|---|---|
| harnessType | String | OPENCODE / KIMI_CODE / DEEPSEEK_HARNESS，unique |
| compactCommand | String | trim 1..64，以 / 开头，默认 /compact |

写方 admin-api；agent-api 只读镜像（autoIndex=false）。非法 → invalid compact command / invalid harness type。

## HarnessSecret（cloudcontainersecrets，cloud-controller）

| 字段 | 类型 | 说明 |
|---|---|---|
| containerId | String | unique（一容器一条） |
| hostEndpoint / hostKey / modelApiKey / modelBaseUrl | String | 必填 |
| modelIds | String | JSON 数组字符串（ModelProvision 的扁平投影） |
| modelContextLengths | String | JSON object 或 null（ModelProvision 的扁平投影） |
| modelProviders | String | 默认 null；`ModelProvision` JSON 字符串（多 vendor 完整清单）；null = 旧版本创建，读取侧回退 `modelIds` / `modelContextLengths` |
| defaultWorkspace | String | 必填 |

不变量：仅 cloud-controller 读写；不得回显；容器终态即删除。

`modelProviders` 为可选字段（agent-gear 2.20.0 起）：非 null 时与旧字段同源双写（旧字段 = 新载荷按组序展开并去重后的投影）；结构上允许 `providers:[]`，正常载荷恒含且仅含一个 `zag` 组（可为空 `models`）且恒首位。

## 相关错误文案（节选，逐字）

- name is required / name is too long / insufficient balance
- harness feature is disabled / cloud host is not configured / control plane unavailable
- Cloud host not found / cloud host is not running / stop the cloud host before deleting
- stopping this cloud host will permanently lose all active sessions
- github account is locked / Github 账号不存在或不属于当前用户
- storage is not attachable / storage is attached / storage is archiving / storage is not archivable
- storage has no archive / storage is not restorable / storage is restoring / storage is not forkable
- storage is not destroyable / not allowed to destroy storage / not allowed to restore storage
- too many workloads (max 5) / workloads exceed 10 / dependency cycle detected / dependency workload not found: <id>
- invalid workload: <id> / invalid workload parameter: <key> / workload is not installable: <name>
- unsupported harness type: <type> / harness workload preset not found: <slug>
- 目标目录已存在其他项目，请修改前缀地址
- Github 工作负载未配置 / 该云电脑正在执行 Github 项目设置
- 仅失败的操作可以重试 / Operation not found
- cloud host is not running / container is not online
- agent-gear upgrade is not supported by the current version / agent-gear upgrade already in progress
