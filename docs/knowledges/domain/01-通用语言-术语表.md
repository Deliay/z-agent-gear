# 通用语言 · 术语表

## 一、身份与归属

| 术语 | 定义 | 事实来源 |
|---|---|---|
| **Account（账户）** | 登录凭据载体，只有 username / passwordHash / passwordless，不含身份语义 | accounts |
| **User（用户）** | 身份主体，挂 accountId 与 tenantId；token 载荷是 userId | users |
| **Tenant（租户）** | 计费与隔离边界，type 为 personal / team；个人租户 _id 复用 userId | tenants |
| **TenantMember（租户成员）** | 成员关系的唯一事实源，role 为 admin / developer | tenantmembers |
| **AdminUser（管理员）** | 后台独立账号体系，与前台 User 不互通 | admin_users |
| **AuthProvider（身份提供方）** | 平台级 OAuth/OIDC 配置，admin-api 唯一写方 | authproviders |
| **ExternalLogin（外部身份）** | 身份锚点 providerId + issuer + subject，不以 email 为锚 | externallogins |

## 二、两套“工作区”必须分清

| 术语 | 模型 | 含义 | 归属 |
|---|---|---|---|
| **Workspace（租户工作区）** | workspaces | 团队协作与资源可见性边界，type=global/normal | tenantId |
| **ControllerWorkspace（项目工作区）** | controllerworkspaces | 控制器上的一个目录 / Git 仓库，即 IDE 里的“项目” | controllerId |

字段语义差异（高频踩坑）：

- **Session.workspaceId** = 租户工作区 Workspace。
- **Session.controllerWorkspaceId** = 项目工作区 ControllerWorkspace。
- **WorkflowInstance.workspaceId** = 项目工作区；**WorkflowInstance.resourceWorkspaceId** 才是租户工作区。
- **CloudHost.workspaceId** = 项目工作区（Git clone 后回写）；**CloudHost.resourceWorkspaceId** 才是租户工作区。
- **CloudStorage.resourceWorkspaceId** = 租户工作区（唯一归属维度）。

## 三、运行时资源

| 术语 | 定义 |
|---|---|
| **Controller（控制器）** | 执行侧代理，type=local/cloud/github，status=online/offline/registering/unbound |
| **CloudHost（云电脑）** | 前台云主机生命周期聚合，创建即启动、停止即销毁 |
| **CloudContainer（云容器）** | K8s 中真实运行的 Pod/Job，cloud-controller 唯一写方 |
| **CloudStorage（云存储）** | 工作区级持久卷，可挂载/归档/复原/fork |
| **CloudWorkload（工作负载）** | 幂等安装脚本单元，workloadKind=standard/harness |
| **Harness** | 运行 ACP Agent 的宿主环境，HarnessType=OPENCODE/KIMI_CODE/DEEPSEEK_HARNESS |
| **基础镜像 BaseImage** | 平台级 Dockerfile 模板，仅 admin-api 持有 |
| **agentGearVersion（工作组件版本）** | `cloudcontainers` 上记录 worker `register` 上报的 agent-gear 版本；`CloudHost.agentGearVersion` 是派生读模型（当前/最新/可升级/检查周期） |
| **立即升级（agent-gear upgrade）** | 用户触发 worker 优雅退出（退出码 0），由 entrypoint 钉版安装并重启；无独立操作单 |

## 四、会话与交互

| 术语 | 定义 |
|---|---|
| **Session（会话）** | 一次 ACP Agent 运行上下文，状态 creating→connecting→idling↔running→disconnected/ended |
| **acpServerType** | Harness 协议标识：opencode / github_copilot / claude_code / gemini_cli / codex / mimo_code / kimi_code / deepseek_harness |
| **AcpMessage** | 追加式消息流（input/output），不挂租户字段，靠会话归属鉴权 |
| **SessionInteraction** | 审批/问询卡片，PENDING→五个终态，60 秒作答有效期 |
| **SessionReview** | 会话预览评审，PENDING→APPROVED/REJECTED/COMMENTED/CANCELLED |
| **TodoItem** | 通知层待办，5 分钟 TTL，不参与作答有效性判定 |

> **60 秒 vs 5 分钟**：SessionInteraction.expiresAt（60s）是作答有效性唯一口径；TodoItem.expiresAt（5min）只是通知过期。

## 五、工作流

| 术语 | 定义 |
|---|---|
| **WorkflowTemplate（模板）** | 可复用节点图，isBuiltin 模板不可改不可删 |
| **ConfiguredWorkflow（已配置工作流）** | 绑定具体控制器与 Agent 配置的节点快照，sourceKind=PLATFORM/REPO |
| **WorkflowInstance（实例）** | 一次运行，节点状态 INITIALIZING/READY/RUNNING/DONE/REJECT/REWORK/FAILED/RETRY_FAILED |
| **nodeKey vs nodeId** | nodeKey 是模板内稳定标识；nodeId 是实例内标识 |
| **HUMAN / AI / FLAG** | 人类节点（唯一首节点）/ Agent 节点 / 自动透传节点 |
| **Stage（阶段）** | 同 stage 的节点共享 worktree |
| **Blackboard（黑板）** | 实例级 key-value 产物与打回记录存储 |
| **打回（reject） vs 返工（rework）** | reject 是下游拒绝上游并使其 REWORK；rework 是节点被要求重做 |

## 六、模型与计费

| 术语 | 定义 |
|---|---|
| **Provider** | 模型供应商（OpenAI / Anthropic 协议），凭据 AES-256-GCM 加密 |
| **Model** | providerId + name 唯一；scope=user/global；pricing 只是便捷视图 |
| **ModelProvision** | 模型下发值对象：`providers[]`（`zag` 首位 + 用户供应商分组）；全量替换语义 |
| **vendorId** | 云电脑内模型分组标识：global 恒 `zag`；user = providerId |
| **Agent Gear** | 平台内置模型的展示归属名（`zag` 的 displayName、网关 `owned_by`） |
| **contextLength（最长上下文）** | 模型上下文窗口（token，正整数）；null=未设置；用户模型可编辑，上游元数据可自动补全，人工值优先 |
| **Gateway** | 控制器端口映射（非模型网关），1..65535，控制器内名称唯一 |
| **credit（积分）** | 对外展示单位；1 credit = 100 分（CENTS_PER_CREDIT） |
| **分（cent）** | 计费落库唯一单位，整数，禁止浮点参与资金运算 |
| **可用余额** | cashBalance + giftBalance + creditLimit − frozenAmount |
| **Reservation（预留）** | 容器按时长计费的冻结/周期结算单，一个 resourceId 一条 |
| **Ledger（账本）** | 追加式资金真相，idempotentKey 唯一，禁改禁删 |
| **Outbox** | 可靠事件投递表，eventId 唯一，producer 区分 cloud-controller / admin-api |

## 七、密钥与工具

| 术语 | 定义 |
|---|---|
| **Valut** | 工作区级加密键值库，namespace=manual/service-* |
| **ValutRef** | entry 与业务数据的引用关系，feature + refId 唯一 |
| **McpServer** | 个人 MCP 注册项，transport=registered_proxy/http/platform |
| **CustomMcpServer** | 工作区级直连 MCP，bearer token 只存 Valut，不存本表 |
| **CustomTool** | 工作区级自定义工具，type=prompt/http，Fragment 支持 Plain/Valut/Parameter |
| **McpSessionEndpoint** | 会话级 MCP 签发凭证，绑定 serverNames 快照与 tokenHash |

## 八、知识库

| 术语 | 定义 |
|---|---|
| **KnowledgeBase** | 工作区级知识库，permissionMode 四档 |
| **KnowledgeBaseDocument** | 仅存活动文档，knowledgeBaseId + path 唯一，删除即释放路径 |
| **KnowledgeBaseEvent** | 追加式全量快照事件（CREATE/UPDATE/DELETE），无更新删除入口 |

## 九、易混淆口径

- **zag vs providerId**：`zag` 是平台保留 vendorId，不是供应商名称；用户供应商的 vendorId 恒为 providerId（ObjectId），改名不影响。
- **模型清单下发 vs 网关调用**：前者是云电脑内 harness 的快照（best-effort、可 `delivered:false`），后者逐请求实时查库（禁用立即 `model_not_found`）。
- **agentGearVersion vs Controller.version**：前者是云电脑 worker 的 agent-gear 版本（`cloudcontainers.agentGearVersion`），后者是控制器注册上报值（`controllers.version`）；不要跨集合混用。
