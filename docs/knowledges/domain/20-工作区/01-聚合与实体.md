# 工作区 · 聚合与实体

## Workspace（workspaces）

| 字段 | 类型 | 必填/默认 | 约束 | 说明 |
|---|---|---|---|---|
| tenantId | ObjectId → Tenant | 必填 | index | 归属租户 |
| name | String | 必填 | trim | global 恒「全局工作区」 |
| type | String | 默认 normal | global / normal | 工作区类型 |
| createdBy | ObjectId → User | 默认 null | — | normal 为创建者；global 为 null |

索引：
- {tenantId,name} unique
- uniq_global_workspace_per_tenant：{tenantId} unique，partial type=global

插件：**不挂**。查询必须显式条件（服务层负责）。

派生字段（GraphQL）：
- memberCount：normal = 成员数；global = 租户成员数
- myRole：当前用户在本工作区所属租户的角色
- readOnly：type=global 且 myRole=developer

## WorkspaceMember（workspacemembers）

| 字段 | 类型 | 必填/默认 | 说明 |
|---|---|---|---|
| workspaceId | ObjectId → Workspace | 必填 | index |
| tenantId | ObjectId → Tenant | 必填 | index，冗余用于校验与级联 |
| userId | ObjectId → User | 必填 | index |

索引：{workspaceId,userId} unique。
插件：**不挂**（显式查询）。

规则：
- global 工作区恒无成员行。
- admin 不依赖本集合（admin 天然可见全部工作区）。
- 添加：仅 team admin；目标须为本租户成员；重复 → already a member。
- 移除：不存在 → not a member。

## 作用域插件字段约定

| 插件 | 触发条件 | 注入内容 |
|---|---|---|
| applyTenantScope | schema 同时有 userId + tenantId | 查询与写入的 tenantId |
| applyWorkspaceScope | schema 有 workspaceId（或配置字段） | 读可见集 / 写收敛 / 只读拦截 |

workspaceField 配置示例：
- 默认字段：workspaceId（如 valutentries、custommcpservers、customtools、ka）
- 工作流域：resourceWorkspaceId（如 workflowtemplates、configuredworkflows、workflowinstances、cloudhosts、cloudstorages、githubaccounts、providers、models）

## 工作区服务关键函数

| 函数 | 语义 |
|---|---|
| ensureGlobalWorkspace(tenantId,…) | upsert global 工作区 + admin 成员行（幂等） |
| accessibleWorkspaces(userId) | 按 TenantMember + WorkspaceMember 计算可访问工作区 |
| canAccess | admin 直通；global 需租户成员；normal 需工作区成员 |
| hasResources(workspaceId) | 11 类资源计数，用于删除保护 |
| buildSessionWorkspaceContext(sessionId,userId) | 会话 → 控制器 → CloudHost.resourceWorkspaceId 回退链 |
| systemWorkspaceContext(workspaceId) | 系统链路上下文（role=admin, readOnly=false） |

## 路径工具（项目工作区路径共用）

- CONTAINER_HOME = /home/worker
- 允许 ~ / ~/ 展开为主目录（仅首字符，~user 拒绝）
- 拒绝空、反斜杠、NUL、任一段 ..
- resolveClonePath(prefix, repo)：repo 必须是 owner/repo 且两段非 . / ..
- 错误：前缀地址不能为空 / 必须以 / 或 ~ 开头 / 包含非法字符 / 不能包含 .. / 仓库格式应为 owner/repo
