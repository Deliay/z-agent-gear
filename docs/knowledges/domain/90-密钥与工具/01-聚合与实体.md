# 密钥与工具 · 聚合与实体

## ValutNamespace（valutnamespaces）

| 字段 | 类型 | 必填/默认 | 说明 |
|---|---|---|---|
| name | String | 必填，trim | manual 或 service-{feature}，全局唯一 |
| displayName | String | 必填 | manual 显示「自定义密钥」 |
| managed | Boolean | 默认 false | name 以 service- 开头 |

索引：uniq_valut_namespace_name（{name} unique）。
插件：**不挂**（全局注册表）。

## ValutEntry（valutentries）

| 字段 | 类型 | 必填/默认 | 说明 |
|---|---|---|---|
| tenantId / workspaceId | ObjectId | 必填 | 归属 |
| namespace | String | 必填 | 引用 namespace 名称（无外键） |
| key | String | 必填，trim 1..128 | 禁空白与控制字符 |
| valueEncrypted | {iv,ciphertext,tag} | 必填 | AES-256-GCM |
| editable | Boolean | 默认 true | 可否就地改值 |
| deletable | Boolean | 默认 true | 可否删除 |
| createdBy | ObjectId → User | 必填 | — |

索引：uniq_valut_entry_workspace_namespace_key（{workspaceId,namespace,key}）；{namespace}；{tenantId}。
插件：workspace-scope（独占型）+ tenant-scope（无 userId → no-op，服务层显式写）。

## ValutRef（valutrefs）

| 字段 | 类型 | 必填/默认 | 说明 |
|---|---|---|---|
| valutEntryId | ObjectId → ValutEntry | 必填 | 被引用条目 |
| feature | String | 必填 | 功能点名（不带 service- 前缀） |
| refId | String | 必填 | 引用方 id |
| refLabel | String | 默认 null | 展示冗余 |
| tenantId / workspaceId | ObjectId | 必填 | 冗余清扫维度 |

索引：uniq_valut_ref_feature_refid（{feature,refId}）；valut_ref_entry（{valutEntryId}）。
插件：tenant-scope；**不挂 workspace-scope**（始终经 entry 归属校验）。

## McpServer（mcpservers）

| 字段 | 类型 | 必填/默认 | 说明 |
|---|---|---|---|
| userId / tenantId | String | 必填，index | 归属 |
| name | String | 必填 | 名称 |
| transport | String | 默认 registered_proxy | registered_proxy / http / platform |
| source | String | 默认 proxy | proxy / manual / platform |
| enabled | Boolean | 默认 true | 启停 |
| command / url / hostname | String | 可空 | 连接信息 |
| headersEncrypted | Object | 可空 | 加密 headers |
| proxyConnectionId | String | 可空，index | 代理连接 |
| status | String | 默认 active | active / offline / disabled |
| tools | [{name,description}] | 可空 | 工具快照 |
| toolsSyncedAt / lastHeartbeatAt | Date | 可空 | 同步与心跳 |

索引：agent-api {tenantId,userId,name} unique；controller-api 镜像 {userId,name} unique。
插件：tenant-scope。

## CustomMcpServer（custommcpservers）

| 字段 | 类型 | 必填/默认 | 说明 |
|---|---|---|---|
| tenantId / workspaceId | ObjectId | 必填 | 归属 |
| name | String | 必填，trim 1..64 | 工作区内唯一 |
| description | String | 默认 null，≤512 | — |
| endpoint | String | 必填 | 仅 http(s)，≤1024 |
| authType | String | 默认 none | none / bearer |
| customHeaders | Map<String,[String]> | 默认 {} | 同名多值；单值 ≤4096；总数 ≤32 |
| bearerValutEntryId | ObjectId → ValutEntry | 默认 null | bearer 必填；none 恒 null |
| createdBy | ObjectId → User | 必填 | — |

索引：uniq_custom_mcp_workspace_name（{workspaceId,name}）；{tenantId}。
插件：workspace-scope（独占型）+ tenant-scope。

## CustomTool（customtools）

| 字段 | 类型 | 必填/默认 | 说明 |
|---|---|---|---|
| tenantId / workspaceId | ObjectId | 必填 | 归属 |
| name | String | 必填，trim 1..64 | 工作区内唯一 |
| description | String | 默认 null，≤512 | — |
| type | String | 必填 | prompt / http |
| args | [Arg] | 默认 [] | key/name/description，≤32 |
| prompt | [Fragment] | 默认 null | type=prompt |
| http.method / http.endpoint / http.insecure / http.bodyType / http.body / http.form / http.headers / http.queries | — | — | type=http |
| createdBy | ObjectId → User | 必填 | — |

Fragment：{type: Plain|Valut|Parameter, value, format: Generic|Json|Uri}。

索引：uniq_custom_tool_workspace_name（{workspaceId,name}）；{tenantId}。
插件：workspace-scope（独占型）+ tenant-scope。

## McpSessionEndpoint（mcpsessionendpoints）

| 字段 | 类型 | 必填/默认 | 说明 |
|---|---|---|---|
| sessionId | String | 必填 | unique |
| userId / tenantId | String | 必填 | 归属 |
| mcpServerIds | [String] | 可空 | 个人 MCP 快照 |
| customMcpServers | [{id,name}] | 默认 [] | 自定义 MCP 路由快照 |
| tokenHash | String | 必填 | bcrypt |
| status | String | 默认 active | active / revoked |
| workflowInstanceId | String | 默认 null | 工作流作用域 |
| expiresAt | Date | 默认 null | 普通会话 now+TTL；workflow 为 null |

索引：sessionId unique；{status}；agent-api 另有 {tenantId}；**agent-api 无 TTL 索引**，controller-api 镜像有。

## McpProxyKey（mcpproxykeys，controller-api）

| 字段 | 类型 | 说明 |
|---|---|---|
| userId | String | 归属 |
| name | String | 1..100，[a-zA-Z0-9\s\-_]+ |
| keyHash | String | bcrypt；toJSON 删除 |
| keyPrefix | String | 掩码 |
| status | String | active / revoked |
| lastUsedAt | Date | 使用即更新 |

索引：{userId,name} unique。

## 相关错误文案（逐字）

Valut：valut entry not found / valut key already exists / invalid valut key / invalid valut value / valut entry is not editable / valut entry is not deletable / valut entry has refs / global workspace is read-only / Not found / workspace not found / Not authenticated。

Custom MCP：custom mcp server not found / invalid mcp name / invalid mcp endpoint / invalid custom headers / invalid mcp description / bearer token is required / valut entry not found / bearer entry must be manual namespace / bearer entry not editable in place。

Custom Tool：custom tool not found / invalid custom tool name / invalid custom tool description / invalid custom tool args / invalid fragment template / invalid http config / duplicate custom tool name。
