# 领域模型库 · 索引

## 这是什么

本库是 **ZeroAsh's Agent Gear** 平台的领域模型知识库，按 **限界上下文（Bounded Context）** 组织。
内容来源为代码事实（Mongoose 模型、GraphQL/OpenAPI/AsyncAPI 契约、服务层状态机），不写入推测结论。

## 组织方式

- 每个限界上下文一个目录，目录内两篇文档：
  - **00-上下文概览**：职责边界、聚合清单、核心不变量、状态机、领域事件、对外契约、跨上下文关系、口径陷阱。
  - **01-聚合与实体**：字段级明细（字段、类型、默认值、约束、索引），可直接对照代码。
- 根目录三篇：本索引、通用语言、上下文地图。

## 阅读路径建议

1. 新人入门：本索引 → 01-通用语言 → 02-上下文地图 → 50-会话与交互 → 60-工作流。
2. 改计费：80-计费与计量 → 40-云资源与Harness（容器生命周期事件）→ 70-模型网关（模型价目）。
3. 改模型下发/云电脑模型配置：70-模型网关（ModelProvision 构建口径）→ 40-云资源与Harness（secret 落地/事件）→ 50-会话与交互（ACP 选项缓存）。
4. 改云电脑工作组件升级：40-云资源与Harness（版本/升级流程）→ 70-模型网关（2.20.0 能力门禁）→ 02-上下文地图（链路）。
5. 改权限：10-身份与租户 → 20-工作区 → 30-控制器（可见性）→ B0-知识库（唯一显式权限矩阵）。
6. 排查线上问题：先看对应上下文的「口径陷阱」，再查状态机允许迁移。

## 事实优先级

**代码 > 契约 > 本库文档**。本库与代码不一致时以代码为准，并回写修正本库。
