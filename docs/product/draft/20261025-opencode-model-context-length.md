# 云电脑 OpenCode 模型上下文长度下发修复

**功能名称**: 云电脑 OpenCode 模型上下文长度下发
**PRD 版本**: v1.0
**创建日期**: 2026-10-25
**作者**: ZeroAsh

## 背景与目标

### 1.1 背景

云容器优化二期已在后台模型设置中支持配置「模型最长上下文大小」，并经模型网关的模型列表接口透出。但云电脑内的 OpenCode 在初始化配置时只拿到了可用模型清单，**没有拿到各模型的上下文长度**：OpenCode 无法感知每个模型的实际上下文窗口，导致会话中上下文管理失真（过早压缩、或对超长上下文模型利用率不足）。

### 1.2 目标

- 创建云电脑时，每个可用模型的「最长上下文大小」随模型清单一并下发到云电脑内的 OpenCode 配置中，OpenCode 据此按各模型真实的上下文窗口工作。
- 未配置上下文长度的模型不下发该字段，OpenCode 对该模型保持自身默认行为。

### 1.3 成功标准

- 后台为模型配置了最长上下文后，新建的云电脑内 OpenCode 对该模型按配置的上下文窗口运行。
- 未配置上下文长度的模型在云电脑内行为与现状一致。
- 上下文长度的下发与模型清单同一次初始化完成，不需要用户或运维在云电脑内手工配置。

## 用户分析

### 2.1 目标用户

- **前台用户**：云电脑使用者，获得与模型真实能力一致的上下文体验。
- **平台运营**：在后台维护模型的最长上下文配置，配置后对新创建的云电脑生效。

### 2.2 用户场景

| 场景 | 用户角色 | 目标 | 痛点 |
|--|--|--|--|
| 云电脑内使用长上下文模型 | 前台用户 | OpenCode 按模型真实上下文窗口工作 | 配置缺失导致上下文被错误压缩或截断 |
| 维护模型上下文配置 | 平台运营 | 后台配置即对新云电脑生效 | 配置目前到不了云电脑内的 harness |

## 功能需求

### 3.1 功能概述

云电脑初始化时，将各可用模型的最长上下文大小随模型清单一起写入 OpenCode 配置。

### 3.2 功能列表

| # | 功能 | 说明 |
|---|------|------|
| F1 | 上下文长度随模型清单下发 | 创建云电脑时，已配置最长上下文的模型在 OpenCode 配置中携带该值 |
| F2 | 未配置模型保持默认 | 未配置最长上下文的模型不携带该字段，OpenCode 保持自身默认 |

### 3.3 用户操作流程

```mermaid
flowchart LR
    A[平台运营在后台维护模型最长上下文] --> B[前台用户创建云电脑]
    B --> C[云电脑初始化完成]
    C --> D[OpenCode 按各模型上下文窗口运行]
```

### 3.4 页面/界面描述

无新增界面；沿用既有后台模型设置入口。

### 3.5 异常与边界情况

- 模型未配置最长上下文：该模型不下发此字段，行为与现状一致。
- 存量运行中的云电脑不受影响；配置对新建云电脑生效。

## 四、非功能需求

- 不引入新的用户操作步骤；初始化耗时与现状一致。

## 五、依赖与约束

- 依赖后台模型设置的最长上下文配置能力（云容器优化二期已交付）。
