1. 整体视觉风格与设计原则

Aesthetic Direction

面向长时间高频使用 Agent 协同、DAG 工作流与代码审阅的研发人员，坚持克制、低视觉噪点、高信息辨识度的精密工程美学。

清晰高于密度

采用「56px Activity Rail 一级导航轨 + 可折叠 Context Panel + MainStage 主舞台」分离高频领域，终结无限纵向折叠手风琴。

表面层级优先于重边框

通过 OKLCH 四级微明度差（Surface-0 → Surface-3）自然分层，仅以 1px 低饱和度描边辅助分割，亮暗模式同等耐久。

零微字号与性能感知

严禁任何 < 12px 微字号（静态单测强制阻断）；「已归档」常驻折叠、无冗余计数、展开懒加载，与聚合查询契约一致。
